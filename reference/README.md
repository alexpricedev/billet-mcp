# Reference copy: billet-cms's MCP plumbing

A verbatim copy of the remote-MCP surface from [alexpricedev/billet-cms](https://github.com/alexpricedev/billet-cms) at `4c1e123`, paths kept as they are there (`app/src/server/…`). It's here because Fettle's bays can only read this repo, and issue #1 ports this code into the package.

Not part of the package: nothing imports it, it isn't built or tested, and it imports billet-cms modules that don't exist here. The CMS's own tools (`mcp/tools/`) are left out.

**The PR that closes #1 deletes this folder.**
